# 📚 Exemplos Práticos - RPG Character Vault

## 🎭 Exemplo 1: Criando um Personagem de D&D 5e do Zero

### Cenário
Você quer criar um Mago Elfo de nível 3 para uma campanha de D&D 5e.

### Passo a Passo

1. **Criar Ficha Personalizada**
   - Menu → "Criar Ficha" → "Ficha Personalizada"

2. **Informações Básicas**
   ```
   Nome: Eldrin Valorion
   Sistema: D&D 5e - Forgotten Realms
   Classe: Mago (Escola de Evocação)
   Nível: 3
   ```

3. **Adicionar Campos Essenciais**
   
   **Raça e Antecedente:**
   - Campo: "Raça" → Tipo: Texto → Valor: "Alto Elfo"
   - Campo: "Antecedente" → Tipo: Texto → Valor: "Sábio"
   - Campo: "Alinhamento" → Tipo: Texto → Valor: "Neutro e Bom"

   **Atributos:**
   - Campo: "Força" → Tipo: Número → Valor: 8
   - Campo: "Destreza" → Tipo: Número → Valor: 14
   - Campo: "Constituição" → Tipo: Número → Valor: 12
   - Campo: "Inteligência" → Tipo: Número → Valor: 18
   - Campo: "Sabedoria" → Tipo: Número → Valor: 13
   - Campo: "Carisma" → Tipo: Número → Valor: 10

   **Combate:**
   - Campo: "Pontos de Vida" → Tipo: Número → Valor: 18
   - Campo: "Classe de Armadura" → Tipo: Número → Valor: 12
   - Campo: "Iniciativa" → Tipo: Número → Valor: 2
   - Campo: "Dados de Vida" → Tipo: Dice → Valor: d6

   **Perícias (Texto Longo):**
   - Campo: "Perícias" → Tipo: Textarea → Valor:
     ```
     Arcanismo +7
     História +7
     Investigação +7
     Medicina +4
     ```

   **Equipamento:**
   - Campo: "Equipamento" → Tipo: Textarea → Valor:
     ```
     - Grimório
     - Componente Arcano
     - Adaga
     - Mochila de Estudioso
     - 15 PO
     ```

4. **Salvar Ficha**
   - Clique em "Salvar Ficha"
   - Pronto! Sua ficha está criada

5. **Adicionar Anotação**
   - Vá em "Anotações" → "Nova Anotação"
   - Título: "Primeira Sessão - Eldrin"
   - Tipo: Diário de Sessão
   - Conteúdo: "Eldrin chegou à taverna..."
   - Associar: Eldrin Valorion

## 🗡️ Exemplo 2: Usando Template de Pathfinder

### Cenário
Criar rapidamente um Lutador Anão para Pathfinder 2e.

### Passo a Passo

1. **Usar Template**
   - Menu → "Templates" → "Pathfinder 2e"

2. **Preencher Template**
   - Nome: "Thorgrim Martelo de Ferro"
   - Sistema: (já preenchido) "Pathfinder 2e"
   - Classe: "Lutador"
   - Nível: "5"

3. **Preencher Campos Pré-configurados**
   - Ancestralidade: "Anão"
   - Herança: "Anão da Montanha"
   - Antecedente: "Guarda"
   - Força: 18
   - Destreza: 12
   - Constituição: 16
   - (continue preenchendo...)

4. **Salvar**
   - Template já tem todos os campos necessários
   - Economiza tempo!

## 🎲 Exemplo 4: Sistema Indie Brasileiro

### Cenário
Criar ficha para um sistema indie (ex: Tormenta20, Old Dragon).

### Passo a Passo

1. **Ficha Personalizada**
   - Criar Ficha → Personalizada

2. **Adaptar para seu Sistema**
   ```
   Nome: Lysara, a Caçadora de Sombras
   Sistema: Tormenta20
   Classe: Caçadora
   Nível: 4
   ```

3. **Campos Específicos do Sistema**
   - Campo: "Raça" → Texto → "Elfa Sombria"
   - Campo: "Divindade" → Texto → "Thyatis"
   - Campo: "Pontos de Vida" → Número → 32
   - Campo: "Pontos de Mana" → Número → 8
   - Campo: "Defesa" → Número → 18
   - Campo: "Força" → Número → 14
   - Campo: "Destreza" → Número → 18
   - Campo: "Constituição" → Número → 12
   - Campo: "Inteligência" → Número → 10
   - Campo: "Sabedoria" → Número → 14
   - Campo: "Carisma" → Número → 8
   - Campo: "Habilidades de Classe" → Textarea
   - Campo: "Poderes" → Textarea
   - Campo: "Itens Mágicos" → Textarea

## 🎯 Exemplo 6: Backup e Migração

### Cenário
Você quer mudar de computador mas manter suas fichas.

### Método 1: Exportar/Importar JSON

**No computador antigo:**
1. Abra cada ficha importante
2. F12 → Console
3. Digite para cada ficha:
   ```javascript
   exportCharacterAsJSON('ID_DO_PERSONAGEM')
   ```
4. Ou exporte todas:
   ```javascript
   // Copie este código no console
   AppState.characters.forEach(char => {
       const dataStr = JSON.stringify(char, null, 2);
       const blob = new Blob([dataStr], {type: 'application/json'});
       const url = URL.createObjectURL(blob);
       const link = document.createElement('a');
       link.href = url;
       link.download = `${char.name}_backup.json`;
       link.click();
   });
   ```

**No computador novo:**
1. Abra o site
2. Use a função de importar JSON
3. Selecione cada arquivo `.json`

### Método 2: Backup Completo

**Backup:**
1. F12 → Console
2. Digite:
   ```javascript
   const backup = {
       characters: localStorage.getItem('characters'),
       notes: localStorage.getItem('notes'),
       profile: localStorage.getItem('userProfile')
   };
   console.log(JSON.stringify(backup));
   ```
3. Copie todo o texto e salve em um arquivo `.txt`

**Restaurar:**
1. F12 → Console
2. Cole o backup e execute:
   ```javascript
   const backup = {/* cole o backup aqui */};
   localStorage.setItem('characters', backup.characters);
   localStorage.setItem('notes', backup.notes);
   localStorage.setItem('userProfile', backup.profile);
   location.reload();
   ```

## 🎨 Exemplo 7: Personalizando Templates

### Cenário
Criar um template personalizado para seu grupo.

### Criar Template de "Sistema da Mesa"

**Arquivo: custom_template.json**
```json
{
  "name": "Sistema da Nossa Mesa",
  "system": "Homebrew RPG",
  "fields": [
    { "name": "Conceito", "type": "text", "value": "" },
    { "name": "Origem", "type": "text", "value": "" },
    { "name": "Corpo", "type": "number", "value": 5 },
    { "name": "Mente", "type": "number", "value": 5 },
    { "name": "Alma", "type": "number", "value": 5 },
    { "name": "Energia Vital", "type": "number", "value": 10 },
    { "name": "Pontos de Ação", "type": "number", "value": 3 },
    { "name": "Habilidades", "type": "textarea", "value": "" },
    { "name": "Equipamento", "type": "textarea", "value": "" },
    { "name": "Conexões", "type": "textarea", "value": "" }
  ]
}
```

**Como adicionar ao site:**
1. Edite `js/templates.js`
2. Adicione seu template em `CharacterTemplates`
3. Ou use a função de importar template
